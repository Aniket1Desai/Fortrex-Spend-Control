## Bug Report: Dataverse 400 Error (Invalid Property 'sct_name')
When creating/updating an SCT request, Dataverse throws a 400 error:
`Invalid property 'sct_name' was found in entity 'Microsoft.Dynamics.CRM.sct_request'. The property 'sct_name' does not exist.`

## Root Cause
The code is sending an unauthorized property `sct_name` in the OData payload. In our Dataverse schema, `sct_request` does NOT have a column named `sct_name`. The primary name/autonumber field is `sct_sct_reference`.

## Mandatory Action: Comprehensive Payload & Schema Validation Audit

- **Category:** `sct_Category` -> Number (Choice option set).
